## 🎯 عن المشروع

تطبيق ويب تفاعلي ومفتوح المصدر، تم بناؤه باستخدام **Streamlit** لمساعدة المستثمرين في السوق المصري على اتخاذ قرارات استثمارية مدروسة. يقوم التطبيق بسحب أحدث بيانات عطاءات أذون الخزانة بشكل آلي من موقع البنك المركزي المصري ويحولها إلى أرقام ورؤى واضحة.

## ✨ الميزات الرئيسية

| الميزة | الوصف |
| :--- | :--- |
| **📊 جلب آلي للبيانات**  | سحب أحدث بيانات العطاءات مباشرة من موقع البنك المركزي المصري لضمان دقة الأرقام مع آلية إعادة المحاولة التلقائية. |
| **🧮 حاسبة العائد الأساسية**  | حساب صافي الربح، الضرائب، ونسبة العائد الفعلية بدقة عالية (3 أرقام عشرية) مع شرح مفصل للمعادلات. الآجال المتاحة: 91 و182 و273 و364 يومًا (وأي أجل جديد يظهر تلقائيًا). |
| **⚖️ حاسبة البيع الثانوي**  | تحليل قرار البيع المبكر مع خيار استخدام أحدث عائد متاح تلقائياً وحساب الربح أو الخسارة المحتملة. |

| **📨 تنبيهات تليجرام**  | يقارن كل أجل بجلسته السابقة الخاصة به، فتصل تنبيهات عطاءات الخميس (182 و364) حتى لو اختلف تاريخ آخر جلسة بين الآجال. |

| **🔒 لوحة إدارة سرية**  | نظام إدارة متقدم مع تشفير كلمات المرور، إدارة التنبيهات، ومراقبة حالة قاعدة البيانات مع progress bars تفاعلية. |
| **⚙️ أتمتة كاملة (CI/CD)**  | GitHub Actions لفحص جودة الكود، التنسيق التلقائي، الاختبارات الشاملة، وتحديث البيانات المجدول. |
| **🧪 اختبارات شاملة**  | اختبارات وحدة، تكامل (يشمل PostgreSQL حقيقي)، واجهة مستخدم، أداء، أمان، ودقة الحسابات، و12 سيناريو فشل لاتصالات PostgreSQL. |
| **📱 توافق متصفحات**  | اختبارات توافق شاملة مع مختلف المتصفحات لضمان عمل التطبيق على جميع الأجهزة. |

## 🚀 التشغيل محلياً

اتبع هذه الخطوات لتشغيل المشروع على جهازك.

#### 1️⃣ المتطلبات الأساسية
- Python 3.11 أو أحدث.
- متصفح Google Chrome.
- أداة `git`.

#### 2️⃣ تثبيت المشروع
```bash
# انسخ المستودع إلى جهازك
git clone https://github.com/Al-QaTari/Bills-Calc.git

# ادخل إلى مجلد المشروع
cd Bills-Calc

# ثبّت جميع المكتبات المطلوبة
pip install -r requirements.txt

# ثبّت متصفح Playwright (مطلوب لجلب البيانات من موقع البنك المركزي، مرة واحدة فقط)
playwright install chromium
```

#### 3️⃣ تحديث البيانات (خطوة هامة)
```bash
# شغّل سكربت تحديث البيانات لجلب أحدث العوائد
python update_data.py
```
> **ملاحظة:** قد تستغرق هذه العملية دقيقة أو اثنتين في المرة الأولى.

#### 4️⃣ تشغيل التطبيق
```bash
# شغّل تطبيق Streamlit
streamlit run app.py
```
سيفتح التطبيق تلقائيًا في متصفحك على `http://localhost:8501`.

## 🐳 التشغيل باستخدام Docker

يمكنك تشغيل التطبيق بسهولة باستخدام Docker لبيئة معزولة ومتسقة.

#### 1️⃣ المتطلبات الأساسية
- تثبيت Docker على جهازك. يمكنك تنزيله من [الموقع الرسمي لـ Docker](https://www.docker.com/get-started).

#### 2️⃣ بناء صورة Docker

من داخل مجلد المشروع، قم ببناء صورة Docker:

```bash
docker build -t treasury-app .
```

#### 3️⃣ تشغيل حاوية Docker

بعد بناء الصورة، يمكنك تشغيل التطبيق في حاوية Docker:

```bash
docker run -p 8501:8501 -it --name treasury-app-container --env-file .env -v playwright-cache:/home/appuser/.cache/ms-playwright treasury-app
```

سيصبح التطبيق متاحًا في متصفحك على `http://localhost:8501`.

#### 4️⃣ تحديث البيانات داخل حاوية Docker

إذا كنت ترغب في تحديث البيانات يدويًا داخل الحاوية بعد تشغيلها، يمكنك تنفيذ الأمر التالي:

```bash
docker run -it --rm --env-file .env -v playwright-cache:/home/appuser/.cache/ms-playwright -v ${pwd}/data:/home/appuser/app/data treasury-app python update_data.py --force-refresh
```

#### **ملاحظة:** يفضل عند كل ايقاف للمشروع استخدام الامر التالي لضمان ان التعديلات لا تتداخل 

```bash
docker stop treasury-app-container; docker rm treasury-app-container
```

## 🔐 متغيرات البيئة

يمكن وضعها في ملف `.env` (يقرأه التطبيق تلقائيًا) أو في إعدادات المنصة. كلها اختيارية؛ بدون `POSTGRES_URI` يعمل التطبيق على SQLite، وبدون `ADMIN_PANEL_PASSWORD` تبقى لوحة الإدارة مخفية.

| المتغير | الوصف | الافتراضي |
| :--- | :--- | :--- |
| `POSTGRES_URI` | رابط الاتصال بقاعدة PostgreSQL. | غير محدد (SQLite) |
| `PG_POOL_SIZE` | عدد الاتصالات الأساسية في الـ pool. | `3` |
| `PG_MAX_OVERFLOW` | اتصالات إضافية مؤقتة فوق الأساسية (الحد الأقصى = المجموع، أي 6). | `3` |
| `PG_POOL_TIMEOUT` | أقصى انتظار (بالثواني) للحصول على اتصال. | `30` |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | بيانات بوت تليجرام لإرسال التنبيهات. | غير محدد |
| `ALERTS_ENABLED` | `true` أو `false` لتشغيل أو إيقاف تنبيهات تليجرام. | `true` |
| `ALERTS_THRESHOLD` | أقل تغير في العائد (بنقطة مئوية) يُرسل عنده تنبيه. | `0.5` |
| `ADMIN_PANEL_PASSWORD` | كلمة مرور لوحة الإدارة السرية. **مطلوبة لتفعيل اللوحة**: لا يوجد افتراضي، وبدونها تبقى اللوحة مخفية. | غير محدد |
| `ENABLE_ADMIN_PANEL` | `true` أو `false` لإظهار أو إخفاء لوحة الإدارة السرية. | `true` |

> **نصيحة:** تأكد أن مجموع اتصالات التطبيق وGitHub Actions ولوحة الأدمن أقل من حد الاتصالات في خطة قاعدة البيانات لديك. القيم الخاطئة أو الأصغر من الحد الأدنى تُتجاهل ويُستخدم الافتراضي.

## 🧪 الاختبارات

```bash

pytest
```
